      02 / Armonización territorial

      Una regla explícita.
      Cada persona, una vez.

      Se conservan las 333 correspondencias de la clasificación publicada de geo4bolivia. Cada una de las diez unidades afectadas se asigna completa al polígono con mayor superficie compartida.

      343339

      Los seis municipios remanentes conservan su destino. Las cuatro unidades nuevas se incorporan completas al municipio de referencia con el mayor solapamiento.

      Es una aproximación territorial autorizada. Los porcentajes de área no son porcentajes de población ni permiten localizar a cada persona.
